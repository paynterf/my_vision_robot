Current Project State: OAK-D Lite Integration on Raspberry Pi 5Goal
Successfully integrate the Luxonis OAK-D Lite camera with a Raspberry Pi 5 running Ubuntu 24.04 and establish a clean, reproducible Python development environment for future vision-based robot work.Hardware & OS  Raspberry Pi 5  
Ubuntu 24.04 Desktop  
OAK-D Lite connected via USB 3  
Physical monitor attached to the Pi (required for GUI applications)

Virtual Environment (depthai-venv)
A dedicated virtual environment was created specifically for this project:bash

python3 -m venv ~/depthai-venv
source ~/depthai-venv/bin/activate

Key packages installed inside the venv:depthai (version 3.6.1 at time of successful test)
opencv-python
Supporting libraries (numpy, etc.)

The environment is activated with:bash

source ~/depthai-venv/bin/activate

A requirements.txt file was generated from this environment for reproducibility.Important Runtime Requirements
Because the OAK-D Lite examples use OpenCV GUI windows, the following must be set when running code that displays images:bash

export DISPLAY=:0
xhost +local:          # Usually only needs to be run once per login session
